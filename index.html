Why install both?

WakeScout is designed to be your starting point. Use it when you already know which lake you want to check. When you want to compare several lakes and let the conditions decide where you should surf, WakeScout can launch Lake Shootout for you.

What WakeScout looks at

  • Sustained wind
  • Wind gusts
  • Rain probability
  • Sunrise and sunset
  • Air temperature
  • Drive time

WakeScout evaluates every valid 3-hour daylight window and ranks the conditions specifically for wakesurfing.

What you need

  • An iPhone
  • Apple Shortcuts
  • Apple Cloud Pro or ChatGPT
  • iOS 27+

Built-in updates

WakeScout and Lake Shootout automatically check for newer versions when they run. If an update is available, you'll get a notification with the option to install it.
